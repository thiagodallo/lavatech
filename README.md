# LAVATECH

Sistema web de gestão de agendamentos desenvolvido para a Eco Planet, estética
automotiva em Criciúma, SC.

- **DISCIPLINA:** Projeto Integrador: Sistema Web
- **CURSO:** Engenharia de Software - 4ª fase
- **FACULDADE:** UniSATC

## Problema

A Eco Planet controla seus agendamentos manualmente, por WhatsApp e caderno
físico, sem histórico de atendimentos e sem controle de conflito de horário
entre os clientes.

## O que o sistema faz

- Cadastro de clientes e veículos
- Catálogo de serviços de lavagem
- Agendamento com bloqueio automático de conflito, respeitando a capacidade
  de duas vagas de lavagem simultâneas
- Controle de pagamento por atendimento
- Histórico de mudanças de status de cada agendamento
- Alerta de proximidade de horário para o atendente
- Controle de estoque de produtos de estética automotiva, com alerta
  automático de reposição
- Controle de qualidade pós-lavagem, com checklist de quem lavou, horário
  e eventual retrabalho
- Dashboard com indicadores do dia (agendamentos por status, ocupação das
  vagas, faturamento) para o proprietário

## Stack

- **Front-end:** React, Vite, React Router DOM, Context API, Recharts
- **Back-end:** Java, Spring Boot (Spring Web, Spring Security, Spring Data
  JPA), Bean Validation
- **Banco de dados:** PostgreSQL
